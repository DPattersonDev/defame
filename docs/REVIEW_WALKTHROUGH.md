# Walkthrough

Choose **Try local demo**. The banner identifies local sample data and inactive
AI/independent ID verification.

1. Browse stories. Like, switch to Dislike, clear your reaction, comment/reply,
   refresh and try Recent/Popular.
2. Open Groups, search and join/leave one. Create a group. Open a group and use
   + for a group story. Live groups need approval; local sample groups do not.
3. Publish an anonymous story. It should be in the feed and private **Manage my
   submissions**, and absent from the profile timeline.
4. Publish with anonymity off. Check that it appears on the public profile.
   Edit the username/bio and refresh. Try an already-taken username.
5. Try a poll and photo. Local photos stay on-device. Connected videos require
   private upload and human review; the local demo does not upload video.
6. Report a story or request a correction/response. Check Activity. Try blocking
   and unblocking. Read the agreements and switch appearance in Settings.
7. Request an AI rewrite: it should explain that the real server key is needed,
   not pretend to generate AI text. Close/reopen to check persistence.

Discuss whether the story-focused experience, groups, anonymity controls,
profiles and reporting feel clear, and what should change before live testing.
